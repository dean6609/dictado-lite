# Native core baseline — 8 October 2026

Scope: Parakeet-only file CLI, native inference/cancellation and 30-second model
idle lifetime. No tray, physical microphone, overlay, clipboard or installer yet.
Hardware: Ryzen 5 5500X3D, Radeon RX 580 8 GB; Windows x64, Rust 1.99.0 GNU,
LLVM-MinGW 20260922, Vulkan SDK 1.4.363.0. Model revision/hash: models/manifest.json.

Private 48.168-second WAV stayed outside Git. All four outputs exactly matched
the saved Parakeet transcript; this is recognition regression, not a human-validated
WER score. Raw text and audio are not included in this record.

| Run | Model load (ms) | File inference (ms) |
| --- | ---: | ---: |
| New process, first run | 623 | 3420 |
| Same resident engine | 0 | 2815 |
| Same resident engine | 0 | 2822 |
| Same resident engine | 0 | 2814 |

Median warm inference: 2815 ms. The isolated unpruned preparation baseline had
2783/2785/2785 ms across separate warmed processes; this core is about 1.1% slower
in that imperfect comparison, with identical output. Accept extraction for the
removed web/cloud/history stack, much smaller native ASR library, bounded queue
and cancellation checks; do not claim a speed improvement. The earlier Handy
single-run record was 2621 ms and is not a repeated timing distribution. OS/file
caches were not deliberately flushed; a new process is not proof of disk-cold load.

`scripts/measure-core.ps1` runs inference then remains idle for forty seconds,
sampling process counters and Windows GPU Process Memory counters. It does not
trim the working set or otherwise hide allocations. Approximate sustained values:

| State | Resident MiB | Private MiB | GPU dedicated MiB | GPU shared MiB |
| --- | ---: | ---: | ---: | ---: |
| After inference, model resident | 334.5 | 1028.0 | 712.5 | 11.7 |
| After idle model/session destruction | 46.0 | 31.2 | 5.7 | 9.3 |

CPU time remained at 3.766 seconds across the idle samples (counter resolution
limits apply). The first GPU counter query delayed early sampling; these are
sustained measurements, not peak/cold-launch metrics. GPU counters describe OS
process allocations, not a vendor measurement of physical VRAM residency.
Persistent backend/driver state explains some resources after model destruction.

Local checks: format/clippy/release; three invalid-audio/session-gate tests;
explicit native smoke with each of Vulkan and CPU passed in-flight cancellation,
same-session recovery and model/session reload. Synthetic silence is generated
in memory. Local WAV regression command is documented in CONTRIBUTING.

Native ASR DLL reduced from 2,083,328 to 531,456 bytes in this GNU build; the
44,841,472-byte ggml Vulkan shader DLL is unchanged. No WebView/ONNX/cloud/CUDA
dependency exists in the root Cargo tree. Further app/resource/latency/visual
acceptance remains necessary; release-to-insertion time has not been measured.
